# MASTER IMPLEMENTATION PROMPT

## Build a Multilingual AI Voice Booking Agent for Mandi Setu

You are a senior full-stack AI engineer working directly inside the existing **Mandi Setu / Agrovia** monorepo.

Your task is to design and implement a production-quality **AI-powered, multilingual, voice-first farmer assistant** that allows a farmer to speak naturally in a regional Indian language and perform real actions in the existing Mandi Setu application.

Example:

> “रुपेश की मंडी में कल सुबह 9 बजे 100 किलो गेहूं का स्लॉट बुक कर दो।”

The AI must understand the request, query the real database through existing backend/business APIs, find the correct mandi and available slot, validate crop and KG quantity, ask for confirmation, and then create a **PENDING booking request**.

The AI must NEVER fabricate availability, rates, booking IDs, token numbers, QR codes, mandi information, or booking status.

# 60. MOST IMPORTANT RULE

The AI is not allowed to lie.

If the database says:

```text
NO SLOT
```

say no slot.

If the database says:

```text
MANDI NOT FOUND
```

say mandi not found.

If the booking API says:

```text
FAILED
```

say booking failed.

If the booking API says:

```text
PENDING
```

say pending.

If the booking API has not generated a token:

**DO NOT CLAIM THERE IS A TOKEN.**

The farmer's trust is more important than completing a conversation.

Build the feature as a reliable **AI agent over the Mandi Setu transactional backend**, not as a chatbot pretending to perform actions.
